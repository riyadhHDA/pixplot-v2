    Bienvenue dans l'Atlas

    Chaque vignette est une œuvre. Les œuvres qui se ressemblent sont voisines sur la carte.

    Explorer

    • Molette : zoomer · glisser : se déplacer
    • Clic sur une œuvre : sa fiche et ses voisines
    • Panneau de gauche : les groupes, nommés automatiquement

    Chercher

    • Par métadonnées : artiste, style, n° d'œuvre
    • Par description : « Annonciation dans un jardin »
    • Par détail : dans une fiche, tracez un cadre sur l'image

    Quatre regards

    • Forme : composition et motifs · Sujet : ce qu'on décrirait avec des mots
    • Couleur : la palette · Touche : la facture, le trait
    • Menu Vue : une carte par regard, chronologie, géographie

    Travailler

    • Comparer jusqu'à 6 œuvres côte à côte
    • Carnet : gardez vos pistes avec vos notes
    • À vérifier : étiquettes que les voisines contredisent, paires de référence à valider
    • Désaccords : œuvres qu'un regard rapproche et qu'un autre sépare
    • Corpus : ce qui manque au corpus, et ce que voit (ou ne voit pas) chaque regard
